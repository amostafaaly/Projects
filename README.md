# School Management System (C#)
A database-driven C# application that manages the core operations 
of a university — students, instructors, courses, exams, and results. 
Built to replace manual file-based storage with a real relational database, 
giving administrators a fast and reliable way to track academic data.

## Team
- Esraa Ahmed
- Moamen Muhammad

## Domain
School / University Management System

## Tech Stack
- C# / .NET 9
- Entity Framework Core 9
- SQL Server

## Key Features
- Manage Students, Instructors, Courses, Exams, Results
- Full CRUD via Entity Framework Core
- Repository Pattern with IRepository<T>
- Seeded database on first run
